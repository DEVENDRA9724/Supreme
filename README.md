# Supreme Immigration Website

Official responsive web portal for **Supreme Immigration** (An ISO 9001:2015 Certified Company &bull; Estd. 2018), a premier immigration and visa consultancy headquartered in Satellite, Ahmedabad, Gujarat.

---

## 🌟 Key Features

- **Executive Branding & Design System**: High-contrast, mobile-responsive layout crafted in Tailwind CSS and modern custom typography.
- **Client Verified Assets**: Authentic high-resolution logos, ISO 9001:2015 certification seals, MARA (Australia) accreditation, and RCIC (Canada) compliance badges.
- **Interactive Points & CRS Calculator**:
  - Real-time Canada Express Entry Comprehensive Ranking System (CRS) simulator (Age, Education, CLB 9/10 language scores, Foreign experience, LMIA job offer).
  - Australian General Skilled Migration (GSM 189 / 190 / 491) points calculator.
- **Comprehensive Country Guides**: Dedicated pathways for Canada, Australia, United Kingdom, United States, Germany (Opportunity Card / Chancenkarte), and New Zealand.
- **Lead Capture & WhatsApp Integration**: One-click consultation booking routing candidate profile parameters directly to WhatsApp (`+91 9725009890`).
- **Office Location & Directions**: Interactive Google Maps navigation to 211, Iscon Emporio, Beside Star Bazar, Satellite, Ahmedabad.

## 🚀 How to Run Locally

You can serve this static website using any local web server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js http-server
npx http-server -p 8080
```

Then open `http://localhost:8080` in your web browser.
